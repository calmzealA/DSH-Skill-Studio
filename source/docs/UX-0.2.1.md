# 0.2.1 界面调整记录

联合创作：**IT咖啡馆 X 老陈聊AI**。本文供维护界面和说明文档时核对用语，不替代[验证记录](VERIFICATION.md)。

| 原有表达或行为 | 0.2.1 的处理 |
| --- | --- |
| 目标工作区 / Agent 预设 | 工作区 / 模式，沿用 DSH 名称。内置模式本地化，自定义模式名保留。 |
| 切到另一个工作区仍称“当前工作区” | 显示所选工作区的真实名称。 |
| 当前目标已发现 / 未进入所选预设 | 可用 / 此模式不可用；提示解释部分模式不支持本地技能。 |
| 文件状态已保存 · 技能目录已核验 · /菜单已刷新 | 主提示“已保存”，同步详情放到提示图标中。 |
| 全局、原始目录名、重复 Plugins 行 | 个人技能、具体工作区、插件自带；必要时区分 DSH 技能与共享技能。 |
| 路径与高级信息常驻展开 | 保存位置使用问号说明，按需查看路径。 |
| 先检查实际文件和同名冲突，再确认安装 | 从 GitHub 或本地文件添加技能。 |
| 预览并导入技能 / 预览文件 / 安装已检查的技能 | 导入技能 / 下一步 / 导入。导入选择“导入到”，新建和复制选择“保存到”。 |
| 保存错误在页头一闪而过 | 错误留在保存区域，可查看详情、复制错误，适用时重试保存；草稿保留。 |

启用状态与模式支持必须分开显示，不能为了简化文字而把“已启用”写成“当前模式一定可用”。DSH 默认极简模式不提供本地技能；自定义或修改后的模式以实际可用结果为准。

保存短暂占用采取有限重试，不直接覆盖原文件、不绕过外部修改检查。若目录替换与回滚都受阻，显示原文件恢复位置并停止普通重试，避免损坏恢复副本。模拟占用测试不能视为 Windows/macOS 真机验收。

生成的设计预览只展示文案和布局方向，不是运行截图或功能验证证据。
