此次修复：
默认“当前模式”仅显示该工作区、模式真正允许调用的技能；“技能库”单独管理全部扫描文件与只读插件条目。

安装 / 从0.2.1升级：
1. 打开 Skills-Studio-Guide-v0.2.2.html，选择中文或English。
2. 安装 dsh-skill-studio-0.2.2.tgz。外层ZIP是交付包，不能直接安装。
3. DSH Desktop：插件 → 更多 → 安装第三方插件，输入tgz的本机绝对路径，按宿主提示启用/重载。
4. DSH Web：在tgz所在目录运行：
   dsh plugin --profile web add ./dsh-skill-studio-0.2.2.tgz
   PowerShell使用 .\dsh-skill-studio-0.2.2.tgz
5. 安装到原profile，保留0.2.1包用于回退；技能和历史目录保持原位置。

source/ 包含完整源码、预构建lib、中英文档与测试，无node_modules、用户技能或测试专用提供方安装包。
